# 灵记 V5.0 - 多工作区 + AI版

灵感笔记应用，单HTML文件，数据存储在浏览器IndexedDB中。

## 功能特色
- 📝 多工作区隔离管理
- 🤖 AI内联触发（写【指令】@AI）
- 📊 起点中文网标准字数统计
- 📄 按字数智能分页
- 🔍 查找替换
- 📁 拖拽排序
- 💾 备份/导入/导出
- 📱 移动端适配

## 使用方法
直接在浏览器中打开 index.html 即可使用。

## AI功能配置
详见 cloudflare-worker/README.md
